# QuestForge / CoxArcade — Glitch Busters Level 6: Echoes of the Void

A full playable browser-based Python debugging action adventure for mixed 6th–8th grade students.

## Worlds
1. The Obsidian Observatory
2. The Shattered Archives
3. The Mirror Foundry
4. The Storm Citadel
5. The Void Engine

## Upgrades
30 new typed-code repair and boss-hack tasks, 20 integrated multi-step complex puzzle challenges (four per world), five mentor arcs, ten unique secret chamber bosses, evolving robotic character, stronger bosses, more bombs and arrows, longer Overdrive, secrets, artifacts and mission report. All instructional prompts require typed Python, not multiple choice.

## Controls
Arrows/WASD move; E interact; Z sword; C bow; B bomb; X dash; V Overdrive; H heal; J journal; R report; M music. In the code editor: ENTER new line; TAB four spaces; CTRL+ENTER submit; ESC leave.

## GitHub Pages deployment
Create `glitch-busters-level-6`, upload the **contents** of this package to the repository root, and set Settings > Pages > GitHub Actions. The deployment workflow is `.github/workflows/deploy.yml`. If GitHub hides `.github`, create that file directly using Add file > Create new file and paste the supplied workflow contents.

Expected address: https://coxarcade.github.io/glitch-busters-level-6/
